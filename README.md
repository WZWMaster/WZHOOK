## 安装

1. 手机已安装并启用 **LSPosed**（Magisk / KernelSU / APatch 的 Zygisk 版本均可）。
2. 安装本模块 APK，打开一次。
3. LSPosed → 模块 → 启用「WZHOOK」。
4. 作用域勾选要作用的应用（轻漫岛 / 番茄免费小说）。
5. 强制停止目标应用后重新打开；回到 WZHOOK 首页应显示「已激活」。

## 使用

- **首页**：激活状态、框架版本、设备名称、系统版本、官方群组、赞助支持、作者。
- **官方群组**：点 QQ 图标直接进群 `790415455`；点 Telegram 图标直接打开 `https://t.me/WZDD_CT`。
- **右上角齿轮 → 设置**
  - 检测更新：启动时自动检查一次，也可以手动检查；有新版本可一键跳到发布页下载。
  - 更新日志：显示当前版本号、发布日期和历代更新内容，可上下滑动。
  - 关于模块：模块说明、免责声明与侵权联系邮箱。
- **应用页**：适配应用列表，显示目标应用的真实图标与激活状态，支持按名称 / 包名 / 效果搜索。

## 常见问题

- **显示「未激活」**：确认 LSPosed 里已启用模块，且作用域包含目标应用；然后强制停止目标应用再打开一次。
- **显示「未获取到版本信息」**：说明当前没有读到框架服务，确认 LSPosed 版本不太旧，并在 LSPosed 里重新勾选一次作用域。
- **检测更新失败**：需要能访问 GitHub；仓库还没有发布 Release 时也会失败。
- **广告没去掉 / 会员没生效**：目标应用更新后加固与类名可能变化，等模块更新适配。
